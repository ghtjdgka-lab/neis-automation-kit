# 품의·복무 시트 — 우리 학교에 맞게 고치기

> 안쌤이 드린 «품의 자동화 시트» 사본을 **이 선생님 학교**에 맞게 바꾼다
>
> 이 문서는 **클로드에게 주는 지시서**입니다. 선생님이 읽으실 필요는 없습니다.
> 전제: 이 컴퓨터에 neis-automation-kit 가 깔려 있고(지시서 1~3 끝),
> 클로드에 **구글 시트·앱스스크립트 MCP**가 연결돼 있다.

---

안녕. 너는 지금 어느 선생님 컴퓨터에 있어. 이 선생님은 안쌤(방배중 안정연)이 만든
«품의 자동화 시트»를 사본으로 받았어. 그 시트는 **방배중 기준**으로 채워져 있어서
예산 이름·과제카드·결재선이 이 학교와 달라. 너는 이 학교 에듀파인을 «읽기만» 해서 배우고,
그 결과로 시트를 이 학교 것으로 바꿔 줘.

## 0. 지켜야 할 것

- 지시서 3(`3_에듀파인-품의.md`)의 0~3절 규칙을 그대로 따른다 — 한 단계씩, 묻고 나서, 쉬운 말로
- ★ 배우는 동안 에듀파인에서 **[저장]·[삭제]·[결재요청]을 하나도 누르지 않는다.** 읽기만.
  [신규]는 3-2의 «예산선택 창 보기»에서만, 선생님께 묻고 누르고 저장 없이 닫는다
- ★ **시트에 사람 이름을 넣지 않는다** — 결재자·기안자·품의자 성함, 품의번호·문서번호 모두.
  결재선은 «나의결재선» 프리셋 **이름**만 쓴다 (예: «기술수업 (30만원 미만)»). 결재 경로에 찍힌 사람 이름은 옮기지 않는다
- 캡처 이미지에 결재자 성함이 있으면 그 이미지를 열지 말고 선생님께 직접 봐 달라고 한다
- 인증서 암호·연락처는 시트에 넣지 않는다 (컴퓨터 설정에만 있다)
- 구글 시트·앱스스크립트는 **MCP로만** 고친다. 브라우저로 시트를 조작하지 않는다

## 1. 시트와 스크립트 찾기

1. 선생님께 시트 주소를 받는다 (`https://docs.google.com/spreadsheets/d/<시트ID>/edit`)
2. 스크립트 ID 를 받는다 — 시트에서 **[확장 프로그램] → [Apps Script]** 를 눌러 열린 주소
   `https://script.google.com/home/projects/<스크립트ID>/edit` 를 붙여 달라고 한다.
   (시트에 붙은 스크립트는 드라이브 검색에 안 나온다. 브라우저로 찾으러 가지 말고 선생님께 받는다)
3. MCP 로 탭 목록과 스크립트 파일 목록을 읽어 보여준다. 탭 6개(품목·품의정보·복무·지난 품의·품의대장·대기열),
   스크립트 Code·Draft·Capture·Bokmu·BokmuDraft 가 있어야 한다
4. ★ 선생님께: «시트에서 메뉴 [🧾 품의] 를 한 번 누르면 구글이 권한 승인을 물어요. [허용] 해 주세요» —
   이건 도구로 대신 못 한다

## 2. 이 컴퓨터에 링크 받는 장치 깔기 (1분, 한 번만)

```
.\.venv\Scripts\python.exe -X utf8 edufine_punui_link.py 설치
.\.venv\Scripts\python.exe -X utf8 edufine_punui_link.py 확인
```
시트의 [📮 품의 올리기]·[🕘 복무 올리기] 버튼이 이 컴퓨터의 키트를 부르게 된다.

## 3. 우리 학교 품의 배우기 (읽기만, 학교 밖이면 run_vpn.py 로 감싼다)

1. **지난 품의 읽기** — 올해 3월 이후 품의를 최근 순으로 40건까지 읽는다
   ```
   .\.venv\Scripts\python.exe -X utf8 edufine_punui.py 읽기 --시작일 <올해>-03-01 --건수 40
   ```
   ⚠️ 지금 키트는 목록 화면에 보이는 10건만 읽는다(가상 스크롤). 10건뿐이면 그걸로 시작하고 선생님께 그렇게 말한다
2. 읽은 품의를 **세부사업 / 예산 줄**로 묶는다. 예산은 «예산선택 창에서 그 줄에만 있는 글자»
   (보통 세부항목 이름. 예: «기술과실험실습재료비»). 같은 글자가 두 줄 이상에 걸리면 더 긴 글자로 바꾼다 —
   [신규] 를 누르지 않고는 예산선택 창을 볼 수 없으니, 이 확인은 선생님께 «예산선택 창을 한 번 열어 봐도 될까요? 저장 없이 닫습니다» 를 묻고 한다
3. **과제카드** — 묶음마다 대표 품의 1건의 연계기안 문서를 문서등록대장에서 열어 «과제카드» 이름을 읽는다
   (`[생활교양교과교육활동] 생활교양교과교육활동 (5년)` → 대괄호 안만). 못 찾으면 «미확인»
4. **나의결재선 이름**
   ```
   .\.venv\Scripts\python.exe -X utf8 edufine_결재선목록.py
   ```
   이름만 표로 보여 주고(결재자 성함은 표에 넣지 않는다), 선생님께 묻는다:
   «어느 사업·얼마 미만에 어느 결재선을 쓰세요?» — 학교 규칙은 선생님만 안다. 들은 대로 적는다
   결재선이 없으면 지시서 3의 «결재선 만들기»(규정 사진 → edufine_결재선만들기.py)로 안내한다

## 4. 시트를 우리 학교 것으로 바꾸기 (MCP)

바꾸기 전에 «이렇게 바꿀게요» 표를 보여 주고 OK 를 받는다.

| 탭·칸 | 바꿀 것 |
|---|---|
| 지난 품의 | 방배중 줄을 **전부 지우고** 3번에서 배운 줄로 채운다. 열: 요구일자 · 제목 · 세부사업 · 예산 · 과제카드 · 나의결재선 이름 · 품목 요약 · 품의금액 · 개요 첫 줄 (성함·번호 없이) |
| 품의정보 B6 | 데이터 확인(드롭다운) 목록을 이 학교 예산 글자들로 바꾼다 (직접 입력 허용 유지) |
| 품의정보 B2·B6·B7 | 선생님이 제일 자주 쓰는 사업으로 채운다 (B6 을 고르면 B7 과제카드가 따라오지만, MCP 쓰기로는 그 트리거가 안 돈다 → B7 도 직접 쓴다) |
| 품의정보 A17:B20 | 결재선 기준표 — «금액 미만 · 나의결재선 이름». 작은 금액부터. 금액 칸을 비운 줄 = 그 이상 |
| 품의정보 B10 | 비워 둔다 (기준표로 자동). 사업마다 결재선이 다르면 그때그때 적는다고 안내 |
| 품목 | 방배중 예시 줄(우드락 등)을 지우고 머리글만 남긴다 |
| 품의대장·대기열 | 비어 있는지 확인 |
| 복무 J1·J2 | «입력만» · «작게» 그대로 |

스크립트 코드는 **고치지 않는다.** 학교마다 다른 값은 전부 시트 칸에 있다.
(경남처럼 에듀파인 화면이 다른 지역은 시트가 아니라 키트 쪽 문제다 — 지시서 3 «막혔을 때»)

## 5. 연습 한 번 (저장 안 함)

1. 품의정보 B12 «올리기 범위» = «화면 채우기만», B15 «화면» = «보이게»
2. 품목에 싼 물건 1줄 (예산 잔액보다 작게 — 잔액이 적으면 «예산잔액 부족»에서 멈춘다)
3. 선생님께: 메뉴 [🧾 품의] → [📝 품의 기안] → [📮 품의 올리기] → 크롬이 «열기»를 물으면 [열기]
4. 검은 창 마지막 줄 `RESULT_JSON=` 을 그대로 받아 «채움: true · 일치: true» 인지 본다
5. 끝나면 «✍️ 올린 결과 적기» 에 «실패» 라고 적어 그 줄을 다시 올릴 수 있게 되돌리고, 연습 줄을 지운다

## 6. 끝나고 선생님께 드릴 말 (요약하지 말고 이대로)

- 시트에서 바꾼 칸 목록
- 배운 표: 사업 · 예산 글자 · 과제카드 · 결재선 (미확인 칸 표시)
- «진짜로 올릴 때는 B12 를 «결재올림까지» 로 바꾸세요. 잘못 올라가면 결재자께 반려를 부탁하셔야 해요»
