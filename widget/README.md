# 나이스·에듀파인 바로가기 위젯

바탕화면에 떠 있는 작은 단추 여섯 — **[나이스] [에듀파인] [문서등록대장] [공람] [검수] [복무]**.
앞의 넷은 누르면 인증서 자동 로그인까지 해서 그 화면을 맨 앞에 띄운다. 보통 **1~2초**.
**[검수]**는 밀린 물품 검사검수 건을 조회해 목록을 보여 주고, **[등록하기]**를 눌러야 등록한다 (`edufine_inspect.py --go`, 30초~1분). 조회만으로는 아무것도 안 누른다.
**[복무]**는 작은 창에서 종류(조퇴·외출·지각·병조퇴·병외출·병지각)·날짜(단추를 누르면 달력 — 클릭해서 고른다)·시작·종료·사유를 고르고 **[상신]**을 누르면 나이스 개인근무상황관리에 승인요청까지 올린다 (`main_bokmu.py`, 1~2분). 조퇴 종료 시각 기본값은 설정의 **퇴근 시각**, 지각 시작 시각은 **출근 시각**(둘 다 학교마다 달라 설정 창에서 묻는다). 출장·연가는 아직 없다.

왜 빠른가: 느린 건 «크롬을 새로 띄워 인증서 로그인하는 것»(15~35초)이다. 위젯이 뜰 때 두 크롬을
**최소화된 채로** 미리 로그인해 두고, 5분마다 세션을 살려 둔다. 그래서 클릭은 창을 꺼내고 페이지만 옮기면 된다.

## 처음 한 번

**클로드 없이:** 키트 맨 위 `바로가기위젯_설치.cmd` 하나를 받아 더블클릭한다.
«파일 열기 - 보안 경고 · 게시자를 확인하지 못했습니다» 창이 뜨면 **[실행]**. 키트를 `%LOCALAPPDATA%\neis-automation-kit` 에 받아 설치하고(파이썬이 있으면 1~2분, 없으면 5~15분)
마지막에 **설정 창**을 띄운다 — ① 지역(17개 시도 목록에서 고른다) ② 인증서 이름(`C:\GPKI\Certificate\class2` 에서 찾아 채운다) ③ 인증서 암호(●로 가려진다)
④ 출근 시각 ⑤ 퇴근 시각 ⑥ 연락처(선택) → **[저장하고 위젯 켜기]**.

**클로드로 / 이미 키트가 있으면:** `setup.ps1` 뒤에 같은 창을 띄우거나(`.venv\Scripts\pythonw.exe widget\바로가기_설정창.pyw`), 검은 창판 `.\.venv\Scripts\python.exe -X utf8 widget\바로가기_설정.py`.

암호는 파일이 아니라 **Windows 자격 증명 관리자**에만 들어간다. 출결·복무 자동화(`setup_wizard.py`)를 이미 했으면 이 단계는 건너뛰어도 된다 — 같은 설정을 읽는다.

끝나면 바탕화면과 시작프로그램에 **«나이스 에듀파인 바로가기»** 가 생긴다. 더블클릭하면 위젯이 뜨고, 다음 로그인부터는 저절로 뜬다.

> **학교 안(학교망)에서 쓰는 위젯이다 — 학교 밖 EVPN용이 아니다.** 위젯은 EVPN을 켜 주지 않고, EVPN으로 연결된 상태에서 데워지는지도 확인하지 않았다.
> 지역: 17개 시도 나이스·업무포털·K-에듀파인 주소(51개)는 이름 조회로 확인했다. 실제 화면까지 열어 본 곳은 서울뿐이다.

## 쓰는 법

- 단추를 누른다. 처음 한 번(또는 크롬을 닫은 뒤)은 로그인부터 하느라 15~35초, 그다음은 1~2초
- **⋮** 를 끌면 옮겨진다. 오른쪽 클릭: 인증서 설정 · 미리 열어두기 켜고 끄기 · 위젯용 크롬 창 닫기 · 위젯 끄기
- 위젯이 띄운 크롬은 작업표시줄에 **최소화된 채로** 있다 — 이게 «데워진 상태»다. 닫아도 1분 안에 다시 띄워 데운다. 닫은 직후의 클릭만 15~35초
- 출결·복무·품의 자동화와 **크롬 프로필이 다르다** (`chrome_profile_widget_*`). 그래서 자동화가 «프로필 사용 중»으로 막히지 않는다

## 안 될 때

- `%LOCALAPPDATA%\neis-automation\widget.log` 에 무슨 명령이 얼마 걸려 어떻게 끝났는지 한 줄씩 남는다
- «인증서 암호가 저장돼 있지 않아요» → 오른쪽 클릭 → 인증서 설정
- «위젯용 크롬이 이상한 상태예요» → 작업표시줄의 크롬 창을 전부 닫고 다시 누른다
- 자동 로그인이 막히면 크롬 창이 그대로 남는다 — 그 창에서 직접 로그인하면 이어서 진행된다 (최대 10분 기다린다)

## 상벌점 위젯 (하이에듀) — 따로 설치

하이에듀(hiedu.kr) 상벌점을 쓰는 학교용. 위 바로가기 위젯과 따로 뜬다 — **`하이에듀위젯_설치.cmd`** 만 받아 더블클릭.

- 바탕화면에 캐릭터 하나(그림이 없으면 «상벌점» 글자). 마우스를 대면 [상벌점]·[우리반], 누르면 우리 반 상벌점 표가 위젯 안에 펼쳐진다(화면 남는 쪽으로).
- 처음 켜면 설정 창: 하이에듀 아이디·비밀번호, 인증서·인증서 암호, 학년·반 → [저장하고 로그인 확인]. **전부 윈도우 자격 증명 관리자(`neis-automation-hiedu`)에만** 저장한다. 나이스 위젯을 이미 쓰면 인증서·학년·반은 그 설정을 빌려 쓴다.
- [우리반]은 화면에 안 보이는 크롬(headless)으로 로그인해 «자료조회 및 통계 → 학생별 누계자료»를 읽는다(약 9초). 학생 점수는 파일로 남기지 않는다.
- 캐릭터 그림은 캐릭터를 오른쪽 클릭 → **«캐릭터 그림 바꾸기…»** 에서 아무 그림(png·jpg·gif·webp)이나 고르면 바로 바뀐다 — 흰 바탕은 지우고(바깥과 이어진 바탕만, 캐릭터 안 흰색은 남김), 모눈종이 위 도트 그림은 칸마다 한 점으로 만든다. 결과는 `widget\상벌점_그림.png`. «캐릭터 그림 지우기» 는 «상벌점» 글자로. 저작권 있는 캐릭터 그림은 저장소에 넣지 않는다.
- 하이에듀는 학교마다 등록한 인터넷 주소(IP)에서만 로그인된다 — «등록되지 않은 IP» 가 뜨면 잠시 뒤 다시, 자주 그러면 학교 담당자에게 IP 등록 요청.

| 파일 | 하는 일 |
|---|---|
| `하이에듀_위젯.pyw` | 캐릭터 위젯 (tkinter, 투명 바탕). 마우스 대면 단추 막대, 누르면 우리 반 표 |
| `하이에듀_엔진.py` | `open` · `class` · `data`(headless, `DATA <json>`) · `check` · `ready` · `setup` · `close`. 크롬 띄우기·붙기는 `바로가기_엔진.py` 것을 쓴다 (전용 포트 9326) |
